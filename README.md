# 🏝️ 微風群島物語 (Breeze Archipelago)

一款使用 **Three.js** 打造的 **Mobile-Friendly** 3D 低多邊形療癒海島冒險靜態網頁遊戲，專為手機觸控與桌面瀏覽器設計，零建置步驟即可部署於 **GitHub Pages**。

## ✨ 遊戲特色

- **4 座風格迥異的 3D 主題島嶼**：
  - 🏡 **微風港灣（主島）**：阿狸的雜貨商店、淡水鯉魚池塘、廣場長椅與南側港口碼頭。
  - 🌴 **熱帶椰林島（東南外島）**：椰子林、珊瑚沙灘、海灘陽傘、火把與熱帶魚／獨角仙生態。
  - 🌸 **櫻花竹林島（西北外島）**：飄落粉櫻、竹林、紅色鳥居、石燈籠、黃金錦鯉與夜裡發光的流螢。
  - 🏛️ **神秘遺跡島（東北外島）**：古老石柱、懸浮發光星光水晶、月神蛾與雨天限定傳說腔棘魚。
- **自由駕船航海**：於碼頭或岸邊登船出海，支援升級小船（木船 → 乘風白帆船 → 星光探險帆艇），並內建航海地圖與召喚小船功能。
- **釣魚與抓蟲系統**：
  - 18 種魚類（海釣／池塘釣／船釣）搭配互動收線小遊戲。
  - 14 種昆蟲（飛行蝴蝶、發光流螢／月神蛾、地面甲蟲與雨天蝸牛）。
- **商店、升級與換裝**：出售戰利品賺金幣、升級釣竿／捕蟲網／帆船／幸運御守，以及多款即時顯示於 3D 角色的帽子與穿搭。
- **島上動物夥伴與委託任務**：6 位各具特色的動物 NPC（阿狸店長、老海獺船長、小兔花花、海龜阿慢、禪師熊貓、博學貓頭鷹），加上自由漫步的小雞、鴨子、螃蟹、小狐狸與海鷗。
- **日夜循環與天氣系統**：晴朗白天、黃昏、星空夜晚與療癒小雨，不同時段與天氣會出現專屬稀有生物。
- **自動本地存檔**：進度自動保存於瀏覽器 `localStorage`。

## 🎮 操作方式

- **手機／平板**：左下角虛擬搖桿移動或開船、右下角情境按鈕互動／釣魚／抓蟲／登船，手指滑動畫面旋轉視角。
- **電腦**：`WASD` 或方向鍵移動、`空白鍵 / E` 主要動作、`F` 登船／上岸、`1 / 2 / 3` 切換工具、`B` 背包、`N` 圖鑑、`Q` 任務、`M` 航海地圖，滑鼠拖曳旋轉視角。

## 🚀 部署至 GitHub Pages

本專案採用純靜態 HTML / CSS / ES Modules，無須編譯打包：

1. 將檔案推送至 GitHub 儲存庫的 `main` 分支。
2. 開啟儲存庫的 **Settings → Pages**。
3. **Source** 選擇 **Deploy from a branch**，分支選擇 `main`、資料夾選擇 `/ (root)`，點擊 **Save** 即可遊玩！
