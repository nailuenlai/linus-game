# 🏝️ 微風群島物語 (Breeze Archipelago)

一款使用 **Three.js** 打造的 **Mobile-Friendly** 3D 低多邊形療癒海島冒險靜態網頁遊戲，專為手機觸控與桌面瀏覽器設計，零建置步驟即可部署於 **GitHub Pages**。

## ✨ 遊戲特色

- **7 座風格迥異的 3D 主題島嶼**：
  - 🏡 **微風港灣（主島）**：阿狸的雜貨商店、自建海島小屋、微風自然博物館、淡水池塘、廣場長椅與南側港口碼頭。
  - 🌴 **熱帶椰林島（東南外島）**：椰子林、珊瑚沙灘、海灘陽傘、熱帶魚與獨角仙／印度星龜生態。
  - 🌸 **櫻花竹林島（西北外島）**：飄落粉櫻、竹林、紅色鳥居、石燈籠、黃金錦鯉與夜裡發光的流螢。
  - 🏛️ **神秘遺跡島（東北外島）**：古老石柱、懸浮發光星光水晶、月神蛾、黃金鬼鍬形蟲、遠古巨蜥與雨天限定傳說腔棘魚。
  - 🌿 **翡翠雨林島（西南外島）**：高聳雨林巨木、青苔枯木與發光菇，棲息著**赫克力士長戟大兜蟲、南洋大兜蟲、美他利佛細身鍬形蟲、高冠變色龍、翡翠樹蚺、銀龍魚與巨骨舌魚**。
  - 🌋 **赤岩溫泉島（正東外島）**：紅岩火山峰、仙人掌與秘湯溫泉池，可遇見**鬃獅蜥、豹紋守宮、寶石聖甲蟲、溫泉金鱒與藍槍魚**。
  - ❄️ **極光冰晶島（正北外島）**：雪松冰原、雪人與發光冰晶塔，棲息著**帝王鮭、冰海天使、翻車魚、鯨鯊、極光雪蛾與冰晶雪蜥**。
- **豐富生態收集（共 66 種生物）**：
  - 🎣 **30 種魚類**（海釣／池塘釣／船釣）搭配互動收線小遊戲。
  - 🪲 **24 種昆蟲與大型甲蟲**（含赫克力士長戟大兜蟲、南洋大兜蟲、美他利佛細身鍬形蟲、長頸鹿鋸鍬形蟲、大王花金龜、彩虹鍬形蟲、黃金鬼鍬形蟲等）。
  - 🦎 **12 種爬蟲類動物**（綠安樂蜥、微笑守宮、藍尾石龍子、櫻池澤龜、綠鬣蜥、鬃獅蜥、豹紋守宮、印度星龜、高冠變色龍、冰晶雪蜥、翡翠樹蚺、遠古巨蜥）。
- **技術型捕蟲＆抓爬蟲系統**：
  - **潛行警戒機制**：奔跑靠近稀有甲蟲與爬蟲會累積警戒度（`👀` → `❗`）並驚嚇逃跑，需使用**潛行（手機「潛行」鈕 / 電腦 `Shift` 或 `C`）**悄悄逼近！
  - **精準瞄準與時機捕捉條**：裝備捕蟲網時地面顯示瞄準光圈，鎖定目標揮網後觸發**精準時機條**，須在指針滑進綠區瞬間點擊捕捉。
  - **稀有種解鎖門檻**：較稀有的甲蟲與爬蟲須先累積捕捉指定數量的一般昆蟲／爬蟲才會於野生環境現身（可在生物圖鑑查看解鎖進度）。
- **自建海島小屋＆3D 室內裝潢**：
  - 於微風港灣西側空地建造專屬**溫馨原木小屋**（並可擴建為**寬敞海景木屋別墅**）。
  - 阿狸雜貨店新增 **16 種 3D 家具與裝飾品**（原木床、海洋藍沙發、茶几、餐桌、書架、衣櫃、地毯、立燈、星光水晶球、盆栽、櫻花盆景、迷你魚缸、甲蟲生態箱、壁爐、黃金獎盃等），進入屋內即可自由移動擺放、旋轉與收納！
- **可進入的 3D 自然博物館與捐贈系統**：
  - 進入微風港灣北側的**微風自然博物館**，可將釣到與抓到的魚類、昆蟲甲蟲與爬蟲捐贈給**館長博博**。
  - 所有捐贈生物皆會即時以 3D 活體／標本展示於**水族生態廳、昆蟲甲蟲廳與爬蟲溫室廳**，並提供研究津貼與里程碑家具獎勵！
- **自動本地存檔**：進度自動保存於瀏覽器 `localStorage`。

## 🎮 操作方式

- **手機／平板**：左下角虛擬搖桿移動或開船、右下角情境按鈕互動／釣魚／潛行／揮網／登船／裝潢，手指滑動畫面旋轉視角。
- **電腦**：`WASD` 或方向鍵移動、`Shift / C` 潛行、`空白鍵 / E` 主要動作、`F` 次要動作（登船／潛行／裝潢）、`R` 旋轉家具、`1 / 2 / 3` 切換工具、`B` 背包、`N` 圖鑑、`Q` 任務、`M` 航海地圖，滑鼠拖曳旋轉視角。

## 🚀 自動部署至 GitHub Pages

本專案已內建 GitHub Actions 工作流程（`.github/workflows/deploy-pages.yml`）：

- 每次推送（`push`）至 `main` 分支時，會自動執行 JavaScript 語法檢查、打包靜態檔案並部署至 GitHub Pages。
- 也可於 GitHub 儲存庫的 **Actions → Deploy to GitHub Pages** 手動點擊 **Run workflow** 觸發重新部署。
